# Archived: PGS-primary landscape analysis

These are the original Phase C scripts from when the project's primary stratifier
was the autism polygenic score (PGS), grouping participants into low/middle/high
PGS tertiles and testing whether high-PGS individuals showed greater variability
in modularity and global efficiency.

The pre-flip state is also tagged in git as `pgs-primary-v1`.

These scripts are not referenced by the active `Snakefile` and are kept here only
for reference / reproducibility of the prior results. The active analysis on the
`behaviour-stratified` branch is stratified by behaviour (`Social_Score` / SDS),
with PGS demoted to an exploratory secondary test in `C6_exploratory_sds_pgs.py`.
